# Install
```
setupATLAS
lsetup git
git clone https://:@gitlab.cern.ch:8443/tla-atlas-run3/FrequentistFramework.git --branch tofitsch_baseline_fit
cd FrequentistFramework
. install.sh
```

# Setup

```
. setup.sh
```

# Run
```
. scripts/run_anaFit.sh
```
